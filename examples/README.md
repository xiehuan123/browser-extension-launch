# 浏览器插件实现例子

这里一共 5 份实现源码和过程记录：上轮隔离试用产生的“摘一句”，以及本轮新增的 4 个工具。每个例子都有独立的 `extension/`、[对话记录](01-sentence-saver/conversation.md)格式的 `conversation.md` 和相关记录。

**当前用户已要求停止继续验证这些例子，它们均没有完整端到端验收通过结论。第五个“网页便签”收到“能打开，但保存或找回失败”的实际反馈，尚未复核或修复。请按源码与过程记录看待，不把它们当作已验收可用产品。**

这些插件都使用 Chrome Manifest V3、原生界面和本机保存，不需要服务器、GitHub 或额外的前端开发软件。**在 Chrome 中加载时，选择某个例子的 `extension/` 文件夹。** 对话及检查记录位于插件目录外，不会混入插件运行文件。

## 对话记录的来源

“摘一句”记录整理自上一轮真实发生的 AI 隔离试用；当时的需求是为了验证技能而设定的场景，并非真人试用访谈。原始插件文件按哈希核对后归档，原规格、决定和检查证据保存在该例子中。

新增例子的场景也由 AI 设定，实现及文件检查在本轮实际执行。每份对话记录说明哪些是场景输入、实际执行摘要，哪些如有则为演示对话；不虚构用户确认、真实浏览器通过或商店上线。本轮没有完整原始逐字会话导出，整理稿不应被当作逐字日志。

## 怎么试用和改成自己的插件

1. 选一个例子，先读其对话及需求说明，了解保存什么、读取什么和能力边界。
2. 将整个例子复制到自己的固定项目目录，再让 AI 修改；保留这里的例子便于对照。
3. Chrome 扩展管理页面打开“开发者模式”，选择“加载已解压的扩展程序”，选中复制后的 `extension/`。
4. 从工具栏打开插件，按该例子的验证记录逐项体验。真实运行结果另行填写，未做的检查继续保持待验证。
5. 要公开上架时，再按主技能执行独立验收、正式素材、账号准备及商店流程。这些例子当前未提交商店。

代码及模拟测试能帮助定位问题；原生入口、权限弹窗、真实剪贴板、重开浏览器后的行为仍以实际 Chrome 检查为准。各例子共用的几何图标用于示例，制作自己的产品时再更换为最终图标。
