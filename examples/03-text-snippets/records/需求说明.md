# 需求说明 · 常用语小抄

- 日期：2026-09-11。
- 来源：用户要求补充常用插件实现例子；本例具体业务场景由 AI 设定，未经独立用户访谈。
- 本例终点：完整本地实现及可重复检查记录；没有商店上线承诺。

## 主要使用路径

填写标题和正文 → 保存小抄 → 输入标题或正文中的关键词 → 点击复制正文 → 到需要的地方自行粘贴 → 下次打开还能找到。

## 已实现范围

- 中文 popup 界面，新建“标题 + 正文”条目，展示列表和总条数。
- 搜索同时匹配标题和正文，忽略关键词首尾空白，英文字母不区分大小写。
- 一键复制正文，不包含标题；正文内部换行保留。
- 删除单条，不改变其他条目。
- 最多 200 条，标题最多 80 字，正文最多 5000 字；拒绝空白和超长内容。
- 首次没有条目时给引导；搜索无匹配时给换关键词提示；读取失败时可重新读取，写入失败时保留原内容和输入；复制失败时可选中正文手动复制。
- 用户输入用纯文本展示，HTML 片段不会作为 HTML 注入页面。

## 权限与数据

| 项目 | 用途 |
| --- | --- |
| `storage` | 用 `chrome.storage.local` 保存小抄；保存后关闭并重开插件仍可读取。 |
| 剪贴板 | 用户点“复制正文”时调用 `navigator.clipboard.writeText` 写入正文；不读取剪贴板，不自动填写网页。真实浏览器内的复制行为仍待验证。 |
| 网页访问 | 没有 `tabs`、网站权限或内容脚本，不读取网页。 |
| 网络与服务 | 没有联网请求、远程脚本、AI 服务、分析统计和账号。 |
| 删除与保留 | 删除后移除本地记录；卸载插件或清除插件数据会丢失，没有云备份或跨设备同步。 |

正文保存位置是当前浏览器。复制之后的正文进入操作系统剪贴板，用户可以粘贴到其他应用；这一步不会由扩展上传到服务器。

## 第一版边界

没有编辑旧条目、分组、快捷键、网页自动填写、跨设备同步或商店发布。允许同名、重复正文，不自动覆盖。搜索关键词不持久保存。多个窗口同时操作的写入没有额外事务锁，不能承诺并发合并；常规逐次操作由 popup 的忙碌状态阻止重复提交。

## 官方依据

2026-09-11 核对 [Chrome Storage API](https://developer.chrome.com/docs/extensions/reference/api/storage) 的本地扩展存储。真实剪贴板与浏览器验收状态以验证记录为准，不将接口调用替身通过等同为用户机器上的复制通过。
