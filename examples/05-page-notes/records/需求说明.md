# 网页便签需求说明

状态：AI 为补充技能实例而设定的本地试用案例，尚无用户对本例功能的逐项确认。版本：0.1.0。日期：2026-09-11。

## 要解决的事

看教程时记下“下次从第三节开始”，看商品时记下“还要比较尺寸”。提醒应跟随这张网页的网址保存，关闭便签再回来仍能找到。

## 第一条成功路径

用户在普通网页点击工具栏图标 → 看见页面标题、网址 → 写便签并点保存 → 关闭弹窗 → 在同一网址重新点图标 → 找回文字 → 修改后保存或删除。

## 已实现范围

- Chrome Manifest V3，原生 HTML/CSS/JavaScript，无构建依赖。
- 只支持 `http:`、`https:` 网页，不支持内部页、本地文件或含用户名密码的网址。
- 每张网址一张便签，最多 10000 个 JavaScript 字符长度单位，保留用户输入中的换行和空格；全空白不保存。
- 显示当前页标题和规范化网址；空态、保存成功、存储失败和网页不可用均有中文反馈。
- “清空输入”仅清空编辑框；“删除本页便签”删除已保存记录；其他网页记录不受影响。
- 不自动保存。弹窗关闭前未点保存的修改会丢失，编辑时提示未保存。

## 网址归属规则

以浏览器提供的网址经标准 URL 解析后的字符串作为页面身份，移除 `#fragment`；保留完整 `?query`，也保留参数顺序。

| 网址变化 | 便签关系 |
| --- | --- |
| `/article?id=1#intro` → `/article?id=1#last` | 同一条便签 |
| `/article?id=1` → `/article?id=2` | 不同便签 |
| `?a=1&b=2` → `?b=2&a=1` | 不同便签 |
| `http:` → `https:` | 不同便签 |

不移除跟踪参数，不猜测两个网址是否内容相同。因此带不同参数的分享链接可能需要分别写便签。采用 `#` 切换整页内容的单页网站也会共用一条便签，这是当前规则的已知边界。

## 权限与数据

| 项目 | 用途和去向 |
| --- | --- |
| `activeTab` | 用户点击工具栏图标后临时获取当前网页 URL 和标题，并在保存/删除前核对页面。 |
| `storage` | 使用 `chrome.storage.local` 保存便签、对应网址、标题、更新时间。 |
| 数据出站 | 无联网请求、上传、统计、第三方 SDK 或远程脚本。 |
| 删除 | 删除本页便签只删除相应存储键；卸载扩展会清除扩展存储。 |
| 未包含能力 | 不读正文、不注入网页、不跨电脑同步、不自动备份、不申请全部网站访问。 |

网址中的查询参数随记录保留，因此本地数据可能包含链接自带的私人参数。本例不把本地存储称为加密保险箱；用户不应将它视作密码管理器。

## 切页和异步保护

打开时记录不可变的标签 ID、窗口 ID、网址和存储键。读取存储结束后核对页面；保存/删除前再次核对当前活动页、URL、导航状态及旧会话是否失效。状态不可确认即拒绝写入。弹窗监听标签切换、目标页加载、网址变化和关闭事件，使旧会话失效并提示重开。

存储键始终取自打开时的会话；浏览器在写入调用发出后导航，最多仍写回原网址，不能把旧页文字存到新页名下。已发出的存储操作无法保证随之后的导航撤销。

## 后续验收与发布范围

人工场景见 `验证记录.md`。本例终点是实现样例和检查记录；商店账号、费用、上传、审核、发布和持续监控均未执行。

## 官方依据

核查日期：2026-09-11。`activeTab` 在用户调用扩展后提供临时当前页访问，可读取 URL、标题；跨来源导航会撤回访问。同源导航可能继续保有权限，因此本例额外检查 URL，不能只用权限是否存在判断是不是原页面。参见 [Chrome activeTab 文档](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)。

`tabs` 命名空间本身不等于必须申请 `tabs` 权限。页面 URL/标题等字段需要相应权限；`pendingUrl` 表示待提交导航且也有权限条件。参见 [Chrome tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs)。
