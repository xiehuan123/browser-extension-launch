## 原试用步骤（已停止执行）

以下仅保留原操作记录；用户已取消本轮验证，不继续执行这些步骤。

1. 打开 Chrome 的扩展管理页 `chrome://extensions`，开启“开发者模式”。
2. 点“加载已解压的扩展程序”，选择本例的 `extension` 文件夹。
3. 打开一张普通网页，点工具栏里的“网页便签”图标。
4. 输入便签，点“保存便签”。关闭后在同一网址重新点图标，检查文字是否还在。

“清空输入”只清空编辑框，已保存的便签还在；“删除本页便签”会删除当前网址的记录。关闭弹窗前需要点保存，未保存输入不会自动保留。

便签、网址和标题只保存在这台电脑的当前浏览器。不同网址分开记录；网址末尾 `#` 后面的定位位置忽略，`?` 后面的参数保留。不同参数可能对应不同商品或文章，因此不会自动合并。浏览器设置页、新标签页和本地文件不支持。
