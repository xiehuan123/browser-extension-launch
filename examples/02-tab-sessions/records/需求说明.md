# 需求说明 · 标签页收纳

- 日期：2026-09-11。
- 来源：用户要求补充常用插件实现例子；本例具体业务场景由 AI 设定，未经独立用户访谈。
- 本例终点：完整本地实现及可重复检查记录；没有商店上线承诺。

## 主要使用路径

打开多个普通网页 → 为当前窗口起一个清单名字 → 保存 → 关闭插件后重开找回清单 → 查看保存的网址 → 重新打开网页。

## 已实现范围

- 中文 popup 界面，输入清单名字后保存当前窗口全部可支持的 HTTP/HTTPS 网页。
- 保存标题、完整网址、创建时间和内部记录 ID；名称最多 60 字。
- 展开清单查看各网页；重新打开全部保存网页，保留当前窗口已有网页。
- 删除保存清单不会关闭已打开网页。
- 浏览器内部页、本地文件、空网址、无法解析的网址、带用户名密码的网址跳过并报告数量。
- 同网址的重复标签保留，清单里的先后顺序与查询结果一致。最多 30 份，每份 200 个网页；超限拒绝保存，不暗中截断网页数。
- 读取失败时禁止写入并提供重新读取；写入失败时保持最后成功状态；恢复部分失败会提示成功和失败数量，不自动反复打开。

## 权限与数据

| 项目 | 用途 |
| --- | --- |
| `tabs` | 用户点击保存时获得当前窗口的网页标题和网址。不能只靠当前单页临时访问权满足整窗口清单。 |
| `storage` | 用 `chrome.storage.local` 在当前浏览器保存清单，重开后找回。 |
| 网站访问权限 | 未申请；没有内容脚本，不读取正文或表单。 |
| 网络与数据去向 | 扩展没有联网请求、远程脚本、分析服务。恢复会让浏览器访问清单中的网站，这是用户点开网页产生的正常网站请求。 |
| 删除与保留 | 删除后从扩展本地记录移除；卸载扩展或清除插件数据会丢失。没有云端副本、备份和跨设备同步。 |

保存的是完整网址，其中可能包含原网页的查询参数，不将其发送到开发者服务器。没有存密码、Cookie、登录状态、表单内容、滚动位置或标签分组。清单同名允许并存。

## 第一版边界

没有编辑清单、导入导出、自动定时保存、跨设备同步、关闭原标签或商店发布。多个窗口同时操作的写入没有额外事务锁，不能承诺并发合并；常规逐次操作由 popup 的忙碌状态阻止重复提交。恢复 200 页的实际性能与关闭 popup 时的完成情况尚未实测。

## 官方依据

2026-09-11 核对 [Chrome Tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs) 的标题/网址权限与创建标签页行为，以及 [Chrome Storage API](https://developer.chrome.com/docs/extensions/reference/api/storage) 的本地扩展存储。链接是实现依据，不代表该扩展已通过浏览器或商店验收。
