## 本例场景（AI 设定）

普通用户做一件事时会打开许多网页，希望把当前窗口存成“旅行攻略”“采购比较”等清单，下一次重新打开。这个场景由 AI 为常见插件样例设定，不是用户另一次真实会话中的原话。

## 本轮实际实现记录

1. 主代理将本例分配为“标签页收纳”，要求独立完整目录、Chrome 原生界面、本地保存、可恢复网页和真实检查证据。
2. 实现前读取技能主文件、开发参考和“摘一句”模板，核对 Chrome 官方 tabs 与 storage 文档；没有读取或收集用户当前真实标签页。
3. 采用原生 HTML、CSS、JavaScript 和 Manifest V3，添加 `tabs` 与 `storage` 权限。只在点“保存”时读取当前窗口标题、网址，并过滤不支持的页面。选择“重新打开”新增标签页，不关闭或替换当前网页。
4. 新建 `extension/`，完成命名保存、展开清单、重新打开、删除、读取失败重试、写入失败保留原记录、恢复部分失败反馈，以及数量限制。
5. 用 Node 标准库运行 `records/tests/core.test.cjs`：16 个测试通过。存储、标签 API 使用隔离替身，覆盖真实 core.js 的逻辑；没有模拟完整浏览器界面，也没有把替身结果称作浏览器试用。
6. 两个 JavaScript 文件语法检查通过；HTML ID 与 JavaScript 选择器的静态对应检查通过；`release_bundle.py check` 通过，错误和警告均为 0。原始记录保存在 `records/`。
