# 标签页收纳

把当前窗口的网页保存成一份有名字的清单，之后查看网址或重新打开，适合整理工作资料、购物比较和旅行攻略。

## 如何加载这个例子

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择**本例里的 `extension` 文件夹**，不要选择整个 examples 文件夹。
4. 在浏览器工具栏的扩展程序菜单中找到本例，点击名称打开。
5. 修改文件后回扩展程序管理页点击该扩展的重新加载按钮，再重新打开。

此目录已经是完整运行目录，不需要安装依赖或执行构建。版本为 `0.1.0`，面向 Chrome Manifest V3；其他浏览器未验证。

## 试用一遍

1. 打开两个普通网站，再打开一个设置页。
2. 打开插件，填写“周末旅行”，点击“保存当前窗口的网页”。
3. 点清单名称查看网页标题和网址；普通网页应保存，设置页应跳过。
4. 关闭并重开插件，清单应仍在。
5. 点击“重新打开”，会新增标签页，已有网页保留；多点一次会再打开一份。
6. 点击“删除清单”，只删除保存的清单，不关闭网页。

最多保存 30 份清单，每份最多 200 个网页。只保存标题和完整网址；网页内容、表单、登录状态、标签分组不会保存。浏览器内部页、本地文件和包含用户名密码的网址会跳过。清单保存在当前浏览器，卸载插件或清除插件数据会丢失；没有跨电脑同步。

## 这个目录里有什么

- `extension/`：完整扩展源文件和 4 种尺寸图标，可独立加载。
- `conversation.md`：本轮任务与实现过程的整理，明确区分用户原话和 AI 设定场景。
- `records/需求说明.md`：场景、功能范围、权限与数据流。
- `records/验证记录.md`：实际检查和待人工验收步骤。
- `records/tests/core.test.cjs` 与 `records/logic-tests.tap`：核心逻辑测试及原始运行结果。
- `records/package-check.json`：本例扩展包静态检查结果。
