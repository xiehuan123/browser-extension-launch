# 专注一会儿：需求说明

日期：2026-09-11；版本：1.0.0；目标：常用插件实现示例，可供本地加载验证。

## 来源与用户路径

本例响应用户“多列举 3–5 个常用插件的实现例子”的要求。专注计时器场景由 AI 在本轮补充设定，不把它视为用户已经逐项确认的独立产品需求。

成功路径：打开插件 → 选择 5/15/25 分钟（默认 25）→ 开始 → 可以关掉窗口 → 再次打开显示按截止时间计算的剩余时间 → 到时显示完成并在图标标记 ✓。

| 功能 | 可观察行为 |
| --- | --- |
| 开始 | 从所选完整时长计时；重复开始不重置正在运行或暂停的计时 |
| 暂停 | 保存精确到毫秒的余时、取消当前提醒；窗口以向上取整的秒显示 |
| 继续 | 从保存余时重新计算截止时间；重复继续不推迟截止时间 |
| 重置 | 清除运行/完成状态，保留所选时长，等待再次开始 |
| 修改时长 | 只在空闲或完成时允许；运行/暂停期间须先重置 |
| 到时 | 进入完成态，不自动开始下一轮；工具栏显示 ✓，窗口给出休息提示 |
| 后台恢复 | 从本地记录恢复，缺失的提醒重新安排；已经过期则直接完成 |
| 异常 | 存储失败提示刷新；提醒设置失败保留计时并说明提醒异常 |

## 权限与数据

| 权限或数据 | 用途与处理 |
| --- | --- |
| `storage` | 本机 `chrome.storage.local` 保存唯一计时状态：版本、所选分钟数、运行状态、剩余毫秒、截止时间 |
| `alarms` | 运行中安排一个到时事件；暂停/重置时清除 |
| 数据接收方 | 无服务器，无第三方，无网络请求 |
| 网页权限 | 不申请站点权限，不读取网页、标签页 URL、浏览记录或剪贴板 |
| 提醒权限 | 不申请系统通知权限，不发声音；使用扩展工具栏自身标记 |
| 清除 | 重置会替换当前计时状态；卸载扩展会删除其本地存储，无跨电脑同步 |

## 已选技术与限制

Chrome Manifest V3，最低 Chrome 120，原生 HTML/CSS/JavaScript，无构建工具和第三方依赖。运行目录完整独立，PNG 图标复用技能原有素材。

后台为状态的唯一写入者，小窗口通过内部消息操作；消息校验扩展 ID 和小窗口来源。事件处理串行执行，避免交错写入。时间逻辑基于本地系统时钟；手动修改时钟可能使余时变长或提前结束。浏览器关闭期间不能展示提醒，恢复后才处理保存状态。提醒不是精确定时服务，休眠或繁忙可能造成延迟。

## 官方依据

核查日期：2026-09-11。

- [Chrome alarms 文档](https://developer.chrome.com/docs/extensions/reference/api/alarms)：设备睡眠期间不会唤醒设备；重要提醒需在后台启动时核对。实现不依赖新版持久化参数，兼容所声明的最低版本。
- [Chrome storage 文档](https://developer.chrome.com/docs/extensions/reference/api/storage)：扩展各上下文可异步读写本地数据，卸载后本地扩展数据删除。
- [后台生命周期](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle)：后台可能休眠，关键状态应存储，不能只依赖内存变量。

真实加载和商店审核不在上述文档核查的证明范围内。
