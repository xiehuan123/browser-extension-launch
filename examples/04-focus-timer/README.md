# 专注一会儿

选 5、15 或 25 分钟，开始后关掉小窗口也会继续计时。支持暂停、继续和重置，到时在工具栏图标上显示 ✓。没有声音和系统通知。

- [插件文件夹](extension/)：Chrome 120 及以上的本地加载目录，无需安装开发工具或构建依赖。
- [实现会话整理](conversation.md)：本轮实际制作过程，场景由 AI 补充设定，非用户逐字对话。
- [需求与数据说明](records/需求说明.md)
- [验证记录](records/验证记录.md)：17 项逻辑测试、静态包检查及仍待进行的浏览器验收。

## 自己试用

1. 打开 Chrome，进入 `chrome://extensions`。
2. 打开“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择此例下的 `extension` 文件夹。不要选择整个 examples 文件夹。
4. 在浏览器扩展菜单中固定“专注一会儿”，再点击它的图标。
5. 选择 5 分钟，点击“开始专注”。先试一次暂停、继续和重置，再完整计时一次，检查图标的 ✓ 和结束提示。

这是可供加载验证的实现示例，尚未在真实 Chrome 工具栏入口完成验收，也未上架。安装上述本地版本属于你的试用操作。

计时记录仅保存在本机。关闭浏览器时无法提醒；再次运行浏览器后会根据保存的截止时间恢复或标为完成。电脑休眠、系统繁忙和修改系统时间均可能影响显示或提醒时机。
