# 摘一句：本地首版规格

状态：范围可实施；真实使用仍待验证。来源是用户本轮原话，无需 GitHub 或发布账号。

## 用户与用途

不会编程的个人用户，在自己的 Chrome 中手动输入句子，保存后关闭弹窗，再打开能够找回。插件不依赖访问的网页。

## 确定的范围

- Chrome 单一浏览器，只给本人本地使用；今天不公开，也不进入商店发布。
- 输入、列表、保存、关闭弹窗后读取。复制和删除保留为简单辅助动作。
- 内容留在当前 Chrome 的本地插件存储，不联网、不同步；无费用、无服务器、无需 GitHub。
- “关掉还能找到”包含关闭弹窗及关闭再开启 Chrome；真正重开浏览器的验证仍待进行。
- 插件命名“摘一句”、单句上限 500 字采用模板的可逆默认值，不宣称用户逐项确认。
- 保存失败不清空输入，不修改原有列表；读取失败阻止覆盖存储并提供重新读取。
- 范围外：网页摘取、多浏览器、跨设备同步、公开商店、登录/付费。
- 提醒：卸载插件或清除插件数据会丢失已存句子。
