# 摘一句：当前归档说明

本例子复用上轮隔离试用的实际产物，8 个运行文件未修改。目标是个人在 Chrome 手动记录句子；网页选区收藏、自动提取正文、跨电脑同步和公开上架不在本例范围内。

功能：输入最多 500 字的句子，保存后列表展示，可复制和删除；重新打开时读取已有内容。保存失败保留输入和旧列表，读取失败禁用覆盖操作并提供重试。

权限只有 `storage`。数据使用 `chrome.storage.local`，包括句子 ID 和正文，保存在当前浏览器配置中；没有网络请求或同步。卸载插件或清除插件数据会删除内容。复制由用户点击触发，复制失败有手动操作提示。

详细原始验收条目见 [原试用规格](original-run/spec.md)，原始选择见 [决定记录](original-run/decisions.md)。其中“用户”是评测场景的角色，非真人访谈。
