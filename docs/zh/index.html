一条完整路径

从想法到可以核对的发布结果

用户只决定产品需求，AI 管理实现细节、检查证据和中断恢复。

  1. 说清想要的结果。技能把日常语言整理成一项小而可用的第一版和明确的完成标准。
  2. 直接试用插件。从浏览器真实入口运行当前成品，并在需要时检查关闭重开和连续两轮使用。
  3. 准备正式发布。源码、安装包、权限、隐私说明、商店文案和实际审核状态都有记录。

安装

把技能加入 Codex

安装器默认不会覆盖已有版本。只有明确使用 --replace 时，才会先备份旧版本再安装。

npm

npx browser-extension-launch install

Git

git clone https://github.com/xiehuan123/browser-extension-launch.git \
  ~/.codex/skills/browser-extension-launch

安装后开启新会话，再调用 $browser-extension-launch。
